# High Cloud Airlines Performance Analysis

## Project Overview
This project analyzes airline performance data to understand passenger trends, route performance, and seat utilization using interactive dashboards.

## Tools Used
- Microsoft Excel
- Power BI
- Tableau
- SQL

## Key Performance Indicators
- Total Passengers
- Available Seats
- Transported Passengers
- Load Factor (%)
- Route and Airline Performance
- Weekday vs Weekend Analysis

## Load Factor
Load Factor (%) = (Transported Passengers / Available Seats) × 100

## Project Objectives
- Analyze airline passenger and flight performance.
- Compare airline and route performance.
- Identify passenger travel patterns.
- Present insights through interactive dashboards.

## Dashboard Previews
Dashboard screenshots are available in the `screenshots` folder.

## Business Value
The analysis helps identify route performance, seat utilization trends, and opportunities to improve airline capacity planning.
